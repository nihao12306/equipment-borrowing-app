# 设备借用系统

用网页登记拍摄设备的借用和归还，按时间查询设备与拍摄间是否空闲。系统会检查重叠预约，也会在飞书模式下读取每日排期中的手写预约。管理员可查看未完成记录、释放设备或取消预约。

## 本地演示

需要 Node.js 20 或更高版本，无需安装第三方依赖。

```sh
npm run demo
```

打开 [本地演示](http://127.0.0.1:8787)，填写虚构姓名和拍摄信息，选择将来的时段，借用一台示例设备。可以尝试再次预约同一时段来查看冲突提示，随后在归还页完成归还。管理员演示密码为 `demo`。

演示只监听本机，记录保存在内存中，重启会重置。演示模式不读取飞书配置，也不调用飞书 API。

## 连接自己的飞书表格

将 `.env.example` 复制为 `.env`，填入飞书应用 ID、应用密钥、电子表格 token、两个工作表 ID，以及独立的管理员密码。飞书应用需有目标电子表格的读写权限。启动命令为 `npm start`。也可使用服务端环境变量注入这些配置。

在同一个飞书电子表格中准备两个工作表，按以下顺序填写第一行表头：

- 设备表 A–H 为「设备ID、类别、设备名称、状态、可直接借用、需管理员确认、数量、备注」。设备 ID 应唯一。借用与确认字段填「是」或「否」。
- 借用记录表 A–T 为「记录ID、关联借用ID、状态、登记来源、借用人、联系方式/飞书名、拍摄主播、拍摄场地、设备ID、设备名称、预约开始时间、预计归还时间、实际归还时间、归还方式、管理员确认人、是否需管理员确认、管理员确认状态、创建时间、更新时间、备注」。

服务会在同一个电子表格里按天创建或更新排期表。生产服务应放在有身份验证的反向代理或可信内网之后。普通查询和归还按共享工作区设计，能够接触到服务的人员可以查询借用记录。单进程负责串行处理预约请求，部署时使用一个实例。
